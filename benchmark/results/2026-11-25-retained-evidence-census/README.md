The original record outcomes were 25 pass, 14 fail, 54 unknown and 11 not applicable. The new analysis has 38 pass, 14 fail, 41 unknown and 11 not applicable. `node recompute.mjs --manifest-sha256 EXPECTED_MANIFEST_FILE_SHA256 --out /absolute/new-census-result`

The expected manifest file digest is supplied by the accompanying delivery receipt. The entry point verifies every included file and recomputes outcome counts, contract changes, layer counts, remaining boundaries and both usage subtotals from census.json. It verifies unchanged admission, business, original failures and costs. It rejects a fabricated clarification pass.

This is an isolated replay of public census arithmetic and consistency. It does not rerun private graders, reconstruct absent evidence, replay all external raw artifacts, call a provider or establish a new scientific result.
